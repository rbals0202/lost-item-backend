분실물 등록 API

1. 입력 데이터
- 사진
- 설명
- 분실 장소
- 분실 날짜/시간

2. 출력 데이터
- Top-5 후보
- 후보 사진
- 설명
- 장소
- 시간
- 종합 매칭 점수
- 이미지 유사도
- 텍스트 유사도
- 색상 유사도
- 장소 유사도
- 시간 유사도

3. API
- 분실물 정보를 백엔드로 보내는 기능
- 주소 : POST /lost-items
- 현재 설명, 장소, 시간을 받아올 수 있음
- 받은 정보를 바탕으로 테스트용 Top-5 후보를 반환함
- 추후 사진도 함께 받을 수 있도록 추가 예정 

4. 처리 흐름
프론트엔드 - 백엔드에서 정보 받기 - AI 모델 및 검색 시스템 - 가장 비슷한 후보 5개 선정 - 백엔드에서 결과 정리 - 프론트엔드

5. 현재 구현 상태
- 백엔드 개발환경 구축
- 백엔드 서버 동작 확인
- 분실물 설명, 장소, 시간 받아오는 기능 + 사진
- 테스트용 가짜 데이터로 Top-5 후보 보여주는 기능
- 후보별 이미지, 텍스트, 색생, 장소, 시간의 유사도 보여주는 기능
- 테스트용 가짜 데이터 별도 함수로 분리
- 실제 이미지 업로드, AI 모델 연동, 검색 DB 연동은 추후에 구현하고

6. 추후 작업 예정
- AI 모델 연동
- 비슷한 분실물 정보를 저장하고 찾을 수 있는 DB 연동
- 가짜 Top-5 대신 실제로 비슷한 후보 검색
- 프론트엔드와 실제 API 연동
